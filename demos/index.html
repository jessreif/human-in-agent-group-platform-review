Playable demos

Click through a participant's session on the Human-in-Agent-Group Platform: consent, training, the Investigation Task with two agent teammates, and the post-task questions. Each demo below matches one condition from the pilot studies.

These are mock-ups, not the live platform. They run entirely in your browser with no server or model, and the agent teammates' replies are canned. To see what agent teammates actually said to participants, open the pilot transcript viewer.

Pilot 1: information environment

Participants were assigned to one of four conditions that varied how much their crates overlapped with their agent teammates' crates and how many intelligence records were in their own case file. There was no workload check-in.

What to expect

  • The task itself lasts 5 minutes; the screens before and after it add a few more.
  • The skip → button in the top bar exists only in the demos. It ends the task early so you can see the post-task screens.
  • Before the task there is an optional page where you can ask an AI about the task rules, as in the pilots. The AI assistant panel that answers questions about your case file is turned off, as it was in the pilots.
  • The completion code at the end is a placeholder, not a payment code.

demos/README.md lists exactly what the demos do and do not simulate.

The demos are generated from demos/template/investigators_demo.html by scripts/build_demo_mocks.py. Running the script also produces every other combination of settings.
